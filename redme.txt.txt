=========== How to Install Cpp ==================

Step 1. 
Install Visual Studio Code

Step 2. 
Install a C++ compiler
C++ needs a compiler to convert your code into an executable program.
We'll use MSYS2 with GCC (MinGW-w64)

1.Open MSYS2 official website.
2.Download the Windows installer.
3.Install it using the default location (C:\msys64).
4.Open MSYS2 UCRT64 from the Windows Start menu.
Run this command: pacman -Syu
If it asks you to close the terminal, close it, reopen MSYS2 UCRT64, and run the update command again if required.
Then install GCC: pacman -S --needed base-devel mingw-w64-ucrt-x86_64-gcc
Wait until installation finishes.

Step 3. 
Add the compiler to Windows PATH
Press the Windows key.
Search for Edit environment variables for your account.
Open it.
Select Path under User variables.
Click Edit → New.
Add this path: C:\msys64\ucrt64\bin

Step 4. 
Install the C++ extension

Open VS Code.
Press Ctrl + Shift + X.
Search for C/C++.
Install the extension published by Microsoft.

Step 5. 
Create your first C++ project
1. Create a folder on your Desktop named:
CPP Practice
2.Open VS Code.
3.Select File → Open Folder.
4.Select your CPP Practice folder.
5.Create a new file called: (hello.cpp)
6. Paste this code:
    #include <iostream>
    using namespace std;

    int main() {
        cout << "Hello, World!" << endl;

        return 0;
    }


Step 6. 
Run your first C++ program
1. g++ hello.cpp -o hello
2. Then run it: .\hello.exe
