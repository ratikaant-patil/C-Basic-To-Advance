Loops Or Looping Statements Meanings executing a block of code until condition get false

Their are total 3 types of looping statements 

1] While
2] Do-While
3] for
4] Nested For Loop

1] While :-
    While loop is used for executing a block of code until condition not get false 
    Syntax :-

        int i = 10;
        while (i>1){
            // code
            // Increment Or Decrement Of variables
        }


2] For :-
    For loop is used to execute a block of code until condition not get false
    Syntax :-

        for(initilization ; condition ; inc / dec){
            //code
        }

    Example :-
        for(int i = 1 ; i<=10 ; i++ ){
            cout << i << " ";
        }


3] Do-While :-
    Do-While is also used to execute block of code until condition get false but it will get executed once if also condition is false from start

    Syntax :-
        do{
            // code
        } while (conndition)

    Example :-
    int i = 10
        do{
            cout << "First in" << endl;
        }while(i<=10)

4] Nested For Loop :-
    Nested For Loop is same as for loop but their are multiple for loop in single for loop

    Syntax :-
        for(initilization ; condition ; inc / Dec){
            for(initilization ; condition ; inc / Dec){
                // Code
            }
        }
